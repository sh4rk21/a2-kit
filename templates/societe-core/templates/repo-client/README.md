# Gabarit de repo de livraison client

À copier à la création du repo `<client>-<projet>` (après signature) : `CLAUDE.md`, `BACKLOG.md`, `JOURNAL.md`, plus le `DESIGN.md` du projet.
Remplacer les `<...>`, recopier les invariants propres au client, dépouiller le devis dans `BACKLOG.md` **avant la première ligne de code**.
Ce qui doit survivre voyage dans le repo (les règles de la société n'y sont pas visibles autrement).
