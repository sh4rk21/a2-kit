# Équipe d'agents de <SOCIETE>

Chaque fiche de ce dossier est le **texte exact des instructions** de l'agent dans Paperclip, sur le modèle officiel de Paperclip

remplacé et la section « Spécificités » complétée. Modèles et politique d'embauche : `socle/equipe/README.md` du kit.

Une fiche ou `configuration.md` change par une PR relue et fusionnée par Alex ; la Base applique ensuite la configuration aux agents.
