# Skills propres à <SOCIETE>

Un dossier par skill (`<nom>/SKILL.md`), créé avec le skill `creer-un-skill` du kit (chercher d'abord s'il existe, PR relue, fusion par Alex).
Un skill propre à la société **précise** un skill du kit (format, style, particularités) ; le kit porte la méthode et prime.
Préfixer le nom par la société si un skill du kit porte déjà ce nom (exemple : `livraison-production-<societe>`).
