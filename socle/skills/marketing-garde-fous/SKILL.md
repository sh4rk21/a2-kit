# Garde-fous marketing A2

Les skills externes (`copywriting`, `content-strategy`, `seo-audit`, `ai-seo`, `ads`, `pricing`, `launch`, `emails`, `onboarding`,
`cold-email`, `social`…) apportent la méthode. Ces règles **priment** en cas d'écart.

1. **Validation humaine** : rien n'est publié, envoyé, lancé ni dépensé sans Alex. Aucun outil de publication ou d'envoi automatique.
2. **Aucun chiffre, avis, témoignage ni logo inventé** : chaque preuve a une source ; un client cité a donné son accord écrit.
3. **Contenu** : Google sanctionne le contenu produit en masse sans valeur ajoutée (« scaled content abuse »). Pas de pages générées
   à la chaîne (`programmatic-seo` seulement sur décision d'Alex, avec des données propres et utiles) ; relecture humaine de tout
   contenu généré ; auteur réel identifié.
4. **Publicité** : budget décidé par Alex ; plafonds journalier et total posés dans la plateforme ; budget de test d'au moins 3 fois le
   coût d'acquisition cible par variante ; règle d'arrêt écrite avant le lancement (arrêt à 2 fois le coût cible sans conversion) ;
   suivi des conversions respectant le consentement aux cookies.
5. **Prix** : les tests portent sur les **nouveaux inscrits seulement** ; les clients existants gardent leur prix ou sont prévenus
   longtemps à l'avance ; pas de prix différents pour des personnes comparables au même moment sans raison objective ; prix TTC pour
   les particuliers ; aucune case précochée ni option payante ajoutée par défaut.
6. **E-mails** : e-mails liés au service permis ; e-mails promotionnels aux particuliers seulement avec leur accord préalable ;
   désinscription simple ; prospection à froid jamais par l'outil de newsletter (skill `email-prospection`).
7. **Lancements** : ne jamais demander, acheter ou échanger de votes (Product Hunt, Hacker News) ; dans les communautés, aide réelle
   d'abord et transparence sur le fait de représenter le produit.
8. **Urgence et rareté** : uniquement si elles sont vraies (pas de faux compte à rebours ni de faux stock) ; pas de parcours piège
   pour l'annulation.
9. **Données personnelles** : prospection selon le skill `prospection` (CNIL) ; pas d'outil d'enrichissement sans base légale ; pas
   d'automatisation ni d'extraction LinkedIn.
10. **IA** : un contenu de synthèse publié pour informer le public est signalé comme tel quand l'AI Act l'exige.
