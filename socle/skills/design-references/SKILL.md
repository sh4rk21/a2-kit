# Références de design

1. **10 à 20 références**, de trois sources :
   - **produits réels** via le MCP Refero (écrans, parcours, styles), recherchés par tâche et par secteur, pas par « joli » ;
   - **le monde du client** : vitrines, signalétique, emballages, imprimés, lieux, matériaux de son métier ;
   - **hors du secteur** : une ou deux références d'un autre domaine qui résolvent le même problème.
2. **Pour chaque référence** : lien ou description, **ce qu'on prend** (une idée précise : une hiérarchie, un rythme, un traitement
   typographique) et **ce qu'on évite**.
3. **Interdits** : récupérer automatiquement Dribbble, Behance ou Pinterest ; copier une interface ; reprendre une identité d'un concurrent.
4. **Livrable** : `design/references.md` avec les liens et commentaires (pas d'images protégées copiées dans le dépôt).

Ensuite : skill `design-direction`.
