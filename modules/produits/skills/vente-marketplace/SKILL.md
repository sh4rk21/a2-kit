# Vente sur ThemeForest et CodeCanyon

**Vérifier les exigences en vigueur** sur le site d'aide d'Envato avant chaque soumission : elles évoluent ; noter la date de
vérification.

1. **Qualité de code** : standards WordPress, **Theme Check** sans erreur pour un thème, aucune erreur PHP ni JavaScript, sécurité
   (nonces, échappement, validation), compatibilité avec les dernières versions de WordPress et PHP.
2. **Séparation thème et plugin** : un thème gère l'apparence ; les fonctionnalités (types de contenu, codes courts) vont dans un plugin
   compagnon. Plugins inclus installés via TGM Plugin Activation (ou un mécanisme équivalent), avec leur licence de redistribution.
3. **Licences** : PHP et HTML sous GPL ; ressources tierces (images, polices, icônes) **toutes licenciées** pour la redistribution,
   listées dans la documentation ; images de démonstration non redistribuables remplacées par des espaces réservés dans le paquet.
4. **Démonstration** en ligne rapide et soignée, à la charte du produit (skills design) ; import de démonstration en un clic.
5. **Documentation** : installation, configuration, personnalisation, FAQ, changelog, crédits.
6. **Licences acheteurs** : licence régulière (un produit final non vendu) et licence étendue (produit final vendu à des tiers) ;
   vérification du code d'achat pour l'activation et le support.
7. **Support** : support inclus de 6 mois (prolongeable par l'acheteur), délais de réponse affichés, réponses préparées par l'agent et
   envoyées par un humain ; mises à jour régulières pour la compatibilité et la sécurité (skill `changelog-version`).
