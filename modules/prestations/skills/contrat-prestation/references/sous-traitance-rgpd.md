# Sous-traitance de données personnelles (article 28 du RGPD)

Quand le prestataire traite des données personnelles **pour le compte** du client (hébergement, CRM, formulaires, maintenance avec
accès à la base), un contrat ou une annexe doit préciser :
- objet, durée, nature et finalité du traitement ; types de données ; catégories de personnes concernées ;
- traitement **uniquement sur instruction documentée** du client ;
- confidentialité des personnes autorisées ;
- **mesures de sécurité** (chiffrement, sauvegardes, contrôle d'accès, journalisation) ;
- **sous-traitants ultérieurs** (hébergeur, outils d'e-mail, IA) : liste, localisation, autorisation du client, mêmes obligations ;
- transferts hors Union européenne et garanties ;
- assistance au client pour les droits des personnes, les analyses d'impact et les violations de données (notification sans délai
  injustifié) ;
- **en fin de contrat** : suppression ou restitution des données, au choix du client ;
- mise à disposition des informations et **audits**.

Le prestataire tient son propre registre des traitements effectués en tant que sous-traitant. Les services d'IA utilisés sur des
données du client figurent dans la liste des sous-traitants ultérieurs.
